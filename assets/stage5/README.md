# Imagens da Etapa 5

Arquivos aguardados nesta pasta:
- registro-sala.webp — fotografia conhecida da sala com o espelho negro.
- envelope-foto-optica.webp — fotografia do envelope.
- cartao-foto-optica.webp — fotografia do cartão.

As imagens não foram criadas nem substituídas por outras evidências.
Quando forem fornecidas, registrar os caminhos correspondentes no Set
availableAssets em stage5-documental.js. Exemplo:
new Set([assets.room, assets.envelope, assets.card]).
Isso evita requisições 404 enquanto os arquivos estão ausentes.

O envelope deve conter na própria imagem: FOTO ÓPTICA BRASIL,
FOB-94-0918-07 e 18 SET 1994.
O cartão deve conter na própria imagem: FOTO ÓPTICA BRASIL;
Revelação • Ampliação • Reprodução; ARQUIVO FOTOGRÁFICO;
Consulte negativos e ordens de reprodução preservados em nosso arquivo.;
fotoopticabrasil.vercel.app.
Essas inscrições não são exibidas como transcrição na interface.
